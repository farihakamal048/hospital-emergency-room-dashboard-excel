# Hospital Emergency Room Dashboard (Excel)</br>
</br>
An interactive, single-page Excel dashboard that gives a monthly report on emergency room performance. I built it while learning from Saltish Dheweri's tutorial.</br>
</br>
## Key Metrics</br>
- Total number of patients</br>
- Average patient wait time</br>
- Patient satisfaction score</br>
- Delay vs on-time share</br>
- Admission status (admitted vs not admitted)</br>
- Gender distribution</br>
- Patients by age group</br>
- Patients by department referral</br>
</br>
## Features</br>
- Year and month slicers (2023/2024, April to March)</br>
- KPI cards with trend sparklines</br>
- Pivot Tables and Pivot Charts linked to one dashboard sheet</br>
- Clean visual layout for quick decision-making</br>
</br>
## Workbook Structure</br>
| Sheet | Purpose |</br>
|---|---|</br>
| Pivot Report | Main pivot tables |</br>
| satisfaction | Satisfaction score analysis |</br>
| Patient Wait Time | Wait time analysis |</br>
| Daily Patient | Daily patient trend |</br>
| Dashboard | Final interactive dashboard |</br>
</br>
## Tools Used</br>
Microsoft Excel (Pivot Tables, Pivot Charts, Slicers, Conditional Formatting)</br>
